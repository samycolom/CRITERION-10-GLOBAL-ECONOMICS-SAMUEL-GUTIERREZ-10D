How is each criterion calculated?
  • Maximax (optimistic): take the best payoff of each alternative and choose the alternative with the highest one.
  • Maximin (pessimistic): take the worst payoff of each alternative and choose the alternative with the highest of those minimums.
  • Minimax Regret: build the regret table, take the maximum regret of each alternative and choose the lowest one.
  • EMV / Bayes: expected value = sum of (probability × payoff). Choose the highest. It needs valid probabilities that add up to 100%.

4. Staged filtering

We start with all alternatives, and each stage removes those that are not the best among the ones still alive: Dominance → EMV → Minimax Regret → Maximin → Maximax. The values used are the same as in section 3.
